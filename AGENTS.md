- Hotel matching for price sources lives only in supabase/functions/_shared/prices/matcher.ts + matching.ts (search + strict scoring); price adapters never guess matches — keeps matches reliable and auditable.
- competitor_price_snapshots rows are written only via insertSnapshots/toSnapshotRow in supabase/functions/_shared/prices/snapshots.ts — every row gets the same full key set (PostgREST bulk insert sends missing keys as NULL) and a failed batch falls back to row-by-row.
- Room category (room_tier) is assigned only in supabase/functions/_shared/prices/roomTier.ts + baseRooms.ts (called from insertSnapshots); 'standard' = the persistent per property×source entry room in price_base_rooms (auto-picked from 30-day history, manual never overwritten), never the day's cheapest room — avoids drifting to suites when standard sells out.
- Location checks in hotel matching resolve districts to provinces via _shared/prices/provinces.ts — business city fields often hold a district name.
- Platform admin bypasses read emails from the PLATFORM_ADMIN_EMAILS secret via supabase/functions/_shared/platformAdmin.ts — no hardcoded admin emails in access checks.
- Saved review-reply closings are appended deterministically after AI quality checks, never generated by the model — preserves the user's exact text and line breaks.
